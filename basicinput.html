Write a program to read a character from the keyboard and display it on the screen.

CODE

{

printf("You entered: %c", c);
}

OUTPUT

You entered: A

Print all ASCII character 0 to 127 ?

CODE

#include <stdio.h>
void main()
{
int i;

{
printf("%c\n", i);
}
}
